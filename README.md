# Klondike Solitaire

Play: https://golgothad.github.io/klondike-solitaire/

Klondike solitaire for phones, Fold devices, tablets and PC. It installs as an app and works offline.

- 8 themed tables, each with its own music, card back and ambient effects (Royal Casino, Walnut Club, Neon City, Enchanted Forest, Nebula, Zen Garden, Coral Reef, Classic 95)
- Drag with tilt and snapping, tap to auto-move, unlimited undo, hints, combos, and an auto-finish button
- Daily deal, draw 1 or 3, Vegas scoring, stats, and save and resume
- Touch, mouse, keyboard and Xbox controller support
- A fireworks win, or the classic bouncing-card win on Classic 95
